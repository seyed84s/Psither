## 🚀 Overview

**Psither** is a revolutionary Android VPN client designed to bypass severe network restrictions with extreme speed and stability. It seamlessly chains Cloudflare WARP with the Psiphon protocol, providing an unbreakable tunnel even in the most hostile networking environments.

Featuring a completely redesigned, vibrant, and highly spirited user interface, Psither is built for users who want both aesthetic perfection and robust performance.

### ✨ Key Features

- **Multi-Country Psiphon Chaining:** Route your Cloudflare WARP traffic through 20+ different Psiphon regions worldwide.
- **Turbo Scan Mode:** Hyper-optimized endpoint scanning to find the fastest connection instantly.
- **Vibrant UI/UX:** A lively, dynamic, and animated interface featuring real-time connection stats.
- **Smart Reconnect & Auto Reprovision:** Stays alive even when the network fluctuates.
- **Split Tunneling:** Choose which apps use the VPN and which bypass it.
- **Advanced Diagnostics:** Built-in real-time logs and connection monitors.

## 🛠️ Building from Source

Psither is built using GitHub Actions. If you wish to build it locally, you will need the Android SDK, NDK, and Rust toolchain for compiling the core components.
